# 星海图像工作台

普通用户前端 UI。项目名：`xinghai-image-studio-ui`。

## 边界

本项目只负责用户界面：登录、注册、图像创作、视频创作、音频入口、作品展示、积分页和账号页。

业务数据不在前端保存。用户、积分、作品、生图记录、兑换码、订单、管理员后台都由后端 `xinghai-studio-console` 负责。

后端入口：

```text
https://img-api.xinghaihub.com
http://100.126.43.55:18080
```

管理员后台：

```text
https://img-api.xinghaihub.com/admin
http://100.126.43.55:18080/admin
```

## 图像创作页

`/studio` 使用后端异步任务接口 `POST /api/image/tasks`，并通过 `GET /api/image/tasks` 每 2 秒同步状态。任务状态由 `CommercialShell` 下的全局 `GenerationProvider` 管理，不再绑定创作页组件：切换到作品、积分或账号页不会终止任务；返回创作页会恢复生成中、成功图片或失败原因；刷新页面后会从后端最近 50 个当前用户任务中恢复。恢复成功结果时跳过 `task.images[].sourceStatus=unavailable`，旧任务源图失效后不再请求 `/p/img/*` 或显示破图；字段缺失和 `unknown` 继续兼容加载。任务 ID 支持缺少 `crypto.randomUUID()` 的内网 HTTP 浏览器环境，不会在提交前因浏览器兼容性中断。

右侧按任务 `count` 显示加载画布和等待时间。成功后完整展示 `task.images[].url`。单图缩放时始终以画布中心定位，缩小不会向下偏移或被底部裁切；缩放工具栏移动到预览标题栏中央，不再占用图片画布；画布内边距缩小，单图使用完整可用宽高。所有生成结果都按图片自身真实宽高使用 `object-fit: contain` 完整适配画布；横图、竖图、方图均以中心为基准显示全貌。缩放只作用于完整适配后的图片，100% 表示完整适应画布，低于 100% 等比例居中缩小。单图和多图点击后均在当前页面打开模糊背景大图预览，点击背景、关闭按钮或按 `Esc` 退出，不再跳转新页面。失败和取消状态会保留后端中文原因，积分变化通过 `GET /api/auth/me` 重新同步。

创作设置按分类拆分，不再让所有模式复用文生图表单：文生图提供模型、比例、数量、分辨率和提示词；图生图额外提供参考强度、构图保持和参考图，局部编辑也归入图生图，通过源图旁的遮罩入口操作；图片编辑包含去背景、换背景、换衣服、换脸、加文字；超分包含 2×、4×、图片变体、老照片修复、人脸增强；批量一致性提供参考图、一致性强度、构图变化和输出设置。图生图和编辑类仍可使用分类专属提示词模板。

提示词模板统一放在右侧预览栏，按当前分类切换。点击模板会填入当前分类提示词框。提示词框支持直接粘贴剪贴板图片：检测到一张或多张图片后自动切换到图生图，并把图片加入“上传参考图”列表；文本粘贴保持原行为，参考图最多保留 4 张。图生图上传源图后显示高对比“局部编辑”按钮；单图工具栏、多图结果卡片和点击图片后的大图预览也提供入口。整个遮罩流程始终停留在图生图，关闭编辑器、提交任务和恢复历史 `edit` 任务都不会进入隐藏分类或空预览。编辑生成结果时，前端发送 `parentTaskId`、被选图片序号、`mode=image`、原图和黑底白色选区遮罩；后端锁定原账号与原会话做原生 Inpainting，再只复制选区内结果，遮罩外保持原图像素。图片和控件保持不可选，正文、提示词、模板说明和状态文字支持鼠标选择复制。

作品页只调用当前 Cookie Session 对应的 `GET /api/gallery`。后端按创建时间倒序返回最新 30 条记录并提供 `sourceStatus`；进入页面立即读取当前账号作品，任务处于 `queued`、`running`、`cancel_requested` 时每 2 秒刷新，任务转为 `succeeded` 后立即刷新。后端已标记 `unavailable` 的历史源图不会发起图片请求，也不会显示为作品卡片或计入“可查看”数量；页面只用一行提示汇总隐藏数量。状态暂不明确的旧记录仍尝试加载，实际失败后同样移出网格。

作品卡片采用图片优先布局：网格内不再铺长提示词，只保留生成类型和时间；完整提示词进入灯箱中的独立滚动区。桌面悬停或键盘聚焦图片时显示“整体变化、局部编辑、下载”浮层，手机双列卡片直接显示三个紧凑图标；灯箱底部始终保留同样的三个操作。可查看作品使用 `object-contain` 完整展示原图。前 12 张作品优先加载，加载期间显示媒体骨架；第 13 张起继续懒加载以控制内存。宽度 360px 以上的手机使用双列紧凑网格，更窄屏保持单列，桌面按 2/3/4 列响应式排列。账号切换或退出时先清空旧账号卡片，避免串号展示。作品进入“整体变化”或 AI 局部编辑时，前端会先携带当前会话读取签名 `/p/img/*`，转成 Data URL 后再提交图片任务，避免相对代理地址被后端当成无效参考图；同时从代理路径保留原任务 ID 和图片序号，使作品页发起的局部编辑也走原生 Inpainting。

## 灵魂画廊

`/soul-gallery` 是独立的静态精选模板库，位于顶部导航“作品”和“积分”之间，不与当前账号的“我的作品”混用。页面内置 19 组本地素材：8 组来自 imagic6，11 组来自 imya。支持按标题、风格、来源和提示词搜索，支持分类筛选、详情大图、完整提示词复制与“一键带入创作”。

画廊素材随前端镜像发布在 `public/soul-gallery-assets/`，浏览时不请求素材站，也不新增后端 API。带入创作只通过 React Router 页面状态把提示词填入现有 `/studio` 输入框，随后立即清理路由状态；异步生图、积分、作品落库和任务恢复仍走原有后端接口。创作提示词上限为 4000 字符，用于容纳完整精选模板。

素材参考：

```text
https://imagic6.xyz/gallery
https://imya.ai/zh/templates
```

站点顶部提供“中文 / English”语言下拉和“浅色 / 暗色 / 彩色”外观下拉。语言默认中文，切换后立即更新商业前端固定文案，并同步 `<html lang>`；语言选择写入 `localStorage` 的 `xinghai-image-studio:language`。用户提示词、作品内容、用户名、邮箱和后端错误保持原文，不做机器翻译。

顶部外观使用 Radix Select 下拉和主题状态，选择后立即更新整站并写入 `localStorage`；历史 `graphite` 值自动迁移为彩色主题。暗色使用深蓝黑、青蓝雾光与浅紫玫紫渐变；彩色恢复为原版克制的青、珊瑚、紫、金四色边缘极光，不再强化导航、注册按钮和生成按钮的高饱和渐变；浅色保持克制。三套主题不改变图像、视频和音频三个独立创作入口的功能与页面结构。

站点名称、Logo、页脚、联系邮箱和文档入口读取 `GET /api/public/site-info`；接口暂不可用时保留“星海图像”默认品牌，不阻塞登录和生图。

桌面端创作工作区最大宽度为 `1240px` 并居中显示，左侧控制区调整为约 `440px`，把更多宽度留给右侧生成预览，参数区独立滚动，底部生成按钮固定可见。提示词输入移到右侧预览区域底部状态栏，与左侧操作栏保持同一水平线，文生图风格模板保留在右侧提示词模板卡片；比例选择恢复为带比例示意图标的原版样式。右侧灵感色板已移除；当前引擎信息移动到左侧底部。提示词输入框与紧凑尺寸的“优化提示词”“生成”按钮保持同一水平线；生成完成状态文字从底栏移除，为提示词输入腾出宽度；优化按钮调用后端 `POST /api/prompt/optimize`，按图像/视频工作流发送对应 profile，后端降级时保留原提示词。灵魂画廊最大宽度为 `1320px`，桌面端使用 3–4 列瀑布流，移动端使用单列并保持横向无溢出。长页面在桌面端由商业外壳独立滚动，图像和视频创作页仍保持一屏工作区。窄屏创作区改为上下排列，不把业务数据保存在前端。


前端 nginx 设置 `client_max_body_size 32m`，与后端图片任务上限一致，避免参考图 Base64 请求在代理层返回 HTTP 413。

## 商用部署方式

商用时仍然部署到自己的服务器。推荐方式：

```text
用户域名 -> nginx/Cloudflare -> xinghai-image-studio-ui:18100 -> /api,/v1 -> xinghai-studio-console:18080
```

前端镜像不放上游 AUTH KEY，不直接管理账号池。后端统一鉴权、扣积分、落库、调度 image2api。

## CF Pages 说明

当前不默认上 CF Pages。先用 Docker 部署在自有服务器，保持 `/api/*` 和 `/v1/*` 同源反代到 `18080`。

后续迁 CF Pages 时，优先用 Cloudflare Pages Functions / Worker 做 `/api` 同源代理。不要把后端 AUTH KEY 写进前端。

### 分类预览与任务隔离

创作工作台的文生图、图生图、图片编辑、超分和批量一致性各自维护提示词、素材、模型、参数、任务状态与结果预览。局部编辑不是独立分类，而是图生图内的遮罩操作；历史 `mode=edit` 路由和任务统一归并到 `image`。切换分类只切换当前视图，不会取消原分类正在执行的图片任务；任务完成后结果只回填到发起它的分类。每个分类顶部从 `GET /api/models?type=image` 动态读取可用模型，并按 operation 能力限制分辨率、质量、输出数量和暂缓功能。

图片任务统一发送 `operation + options + sourceImages.role` 到 `POST /api/image/tasks`，覆盖生成、图生图、局部编辑、抠图、换背景、换衣、换脸、文字、变体、人脸增强和批量一致性；通过 SSE `GET /api/image/tasks/stream` 和 `GET /api/image/tasks` 轮询恢复。离开页面、切换分类或切换到其他导航页都不会打断后端任务；返回时按账号和分类恢复。任务终态会同步积分，失败/取消显示后端原因。生成数量只显示后端支持的 1、2、4 张。同一成功任务的 SSE 心跳即使刷新图片签名，也会复用已渲染 URL，避免每 2 秒重复下载大图。

提示词模板统一放在右侧预览栏，按当前分类切换。提示词框粘贴图片会自动切换到图生图并加入最多 4 张参考图。结果图可下载、打开大图或直接进入局部编辑；大图预览底部常驻“局部编辑”。编辑器的 AI 任务和本地修复统一提交黑底白色选区遮罩，不再把透明兼容遮罩或带涂抹效果的预览图当作任务 Mask。AI 请求固定使用 `mode=image`；编辑生成结果时额外发送父任务 ID 和正确图片序号。后端先做原生 Inpainting，再在成功、作品入库前完成像素合成，遮罩外保持原图。

### 视频与音频创作

`/video` 是独立视频工作台，只提供文生视频和图生视频。页面调用 `GET /api/models?type=video` 动态加载运行就绪模型及其能力，再调用 `POST/GET /api/video/tasks` 和 `GET /api/video/tasks/:task_id` 创建、恢复和轮询任务。文生视频不需要起始图，图生视频接收 PNG/JPEG/WebP 起始图；比例、480p/720p/1080p、5/10/18 秒和积分从模型目录动态渲染。成功后使用原生视频播放器展示 `url`、实际时长、尺寸、进度和状态。两个视频分类的设置、提示词、起始图和预览彼此隔离，离开页面不会停止后端任务。

视频提示词优化调用 `POST /api/prompt/optimize` 的 `text_to_video` 或 `image_to_video` profile。视频接口错误按 `error.code` / `error.message` 解析。`/audio` 当前只有文本转语音和文生音乐的入口展示；后端尚未开放普通用户音频执行接口，因此页面不提交伪造任务。

### 本地图片处理

图片编辑中的去背景、换背景和局部修复分别调用 `/api/image/cutout`、`/api/image/background-replace`、`/api/image/local-mask-edit` multipart 接口，不消耗模型积分。返回的 PNG 只暂存当前工作台，可下载或继续编辑；后端目前没有对应的作品落库接口，所以不会出现在作品栏。

### 图片编辑工作台交互

图片编辑不再复用普通图生图的多参考图列表。换背景、换衣服和换脸固定使用横向双槽：左侧为 `image` 主图，右侧根据当前动作绑定 `background`、`garment` 或 `face` 参考图；上传、粘贴和右侧模板选择统一写入对应角色，最多一张主图和一张专用参考图。去背景和加文字只显示主图槽。切换动作会保留主图并清理不匹配的辅助角色，避免把背景图误当服装或人脸。

文生图提示词框粘贴图片仍进入图生图；图生图、图片编辑、放大/去水印和批量分类内粘贴图片保持当前分类。上传后的主图、普通参考图、背景、服装和人脸缩略图均可点击放大，点击遮罩、关闭按钮或按 `Esc` 退出。

图片编辑右侧不再展示内部执行提示词。换背景、换衣服和换脸会显示随前端镜像发布的本地图片模板，点击后直接作为专用参考图；用户提示词框只保存用户自己的补充要求。固定操作约束继续由后端根据 `operation` 在执行指令顶部注入，前端不把系统要求拼进用户提示词。

添加文字使用后端确定性 `text_overlay`，不调用图片生成模型。上传主图后，右侧画布直接显示文字选框，支持拖动位置、九宫格快捷定位、无衬线/衬线字体、字号滑块和颜色；前端把拖动位置换算为原图像素 `x/y`，不再要求用户填写坐标。当前契约未提供粗体、描边或文字底框输出字段，前端只发送已有的 `fontFamily/fontSize/textColor/position/x/y`，避免预览与最终结果不一致。

创作台标题、说明、状态和参数文字恢复可选择复制；图片、画布和滑块继续不可选。左侧模式栏、参数栏和右侧信息栏保留滚轮/触控滚动，但隐藏系统滚动条。原“超分”入口显示为“放大/去水印”，底层 operation 和模型能力判断不变。
